A belief

Attention is the scarce thing

Most software competes for your attention. We think a study tool should do the opposite: ask for as little as possible, and give the rest back to the work.

Every decision here begins with cognitive load. If an interface element isn’t helping you think, it isn’t there.

How we build

Quiet by default

No streaks, no points.
