A belief

Attention is scarce, and so is a teacher’s time

Most education software asks a great deal of both. We build the opposite: tools that ask students for as little attention as possible, and ask teachers for as little admin as possible, so both can go back to the lesson.

Every decision starts with cognitive load. If something on the screen isn’t helping a student think, or helping a teacher decide, it isn’t there.
